## Pitfalls found

| Pitfall | What happens | Check or fix |
| --- | --- | --- |
| Upload to a theme still `processing` after `themeDuplicate` | `themeFilesUpsert` returns no error, then the duplication overwrites the file with the old one | Poll `theme { processing }` until false, then upload |
| URL-body upload of an invalid section | Returns no `userErrors`, file silently keeps its old content | Always compare `checksumMd5` with the local md5; a TEXT-body upload of the same file shows the real error |
| Schema `header` content over 50 characters | File rejected (visible only with a TEXT body) | Keep every `"type": "header"` content short |
| Default `article.json` carries the "Keeping Perfume" gallery | Every new article shows ten images of another post | Give each text post its own `templates/article.<handle>.json` with breadcrumbs + main-article only, set `templateSuffix` on the article |
| `themeFilesUpsert` / theme publish to the MAIN theme | Blocked by the MCP safety policy | Duplicate the live theme, upload there, the owner publishes |
| Theme appends "– AromaStylist" to `global.title_tag` | A brand suffix in the title doubles | Leave the brand out of the SEO title |
| Shopify CDN caches the page about a minute | A fresh read shows the old title | Re-check after 45 to 60 seconds with a cache-busting query |
| Playwright on the cloud box | Needs `proxy: { server: process.env.HTTPS_PROXY }`, `--ignore-certificate-errors`, `waitUntil: 'load'` (networkidle never settles on Shopify) | Run scripts from inside the repo so `playwright` resolves |
