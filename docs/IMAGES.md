# Картинки для квиза (v2)

Картинки даёт владелица. Подключение: в редакторе темы у каждого блока ответа есть поле «Image».
Пока поле пустое, квиз показывает картинку по умолчанию из конфига.

## Общие требования
- Формат 1:1 (квадрат), минимум 1200×1200 px, JPG или WebP, до 300 KB.
- Без текста на картинке: подпись выводит квиз.
- Одна съёмка / один стиль на весь квиз: свет, фон и цвет как на сайте (кремовый фон, золото, тёплый свет).
- Предмет в центре: на телефоне плитка около 110–170 px, края могут обрезаться.
- Имя файла как в таблице ниже, чтобы агент сразу понял, куда её ставить.
